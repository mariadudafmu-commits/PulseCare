# 💙 PulseCare: Bem-Estar ao Seu Ritmo

O **PulseCare** é uma aplicação móvel voltada para o acompanhamento preventivo do bem-estar emocional, criada especialmente para estudantes universitários e jovens profissionais.

---

## O Problema

O aumento do stresse, da ansiedade e da exaustão emocional tornou-se uma realidade alarmante entre estudantes e jovens profissionais. 
* **Rotinas aceleradas:** A pressão académica e profissional constante reduz o tempo disponível para o autocuidado.
* **Sinais ignorados:** Os primeiros sintomas (como alterações no sono, fadiga leve e oscilações de humor) são frequentemente negligenciados até evoluírem para quadros graves, como o *burnout*.
* **A Oportunidade:** Falta uma ferramenta diária, rápida e acessível que ajude a identificar padrões invisíveis de sobrecarga antes que afetem a saúde mental de forma crítica.

---

## A Solução

O **PulseCare** funciona como um assistente de monitorização diária e preventiva. 
* **Check-ins Rápidos:** Em menos de dois minutos por dia, o utilizador regista o seu humor, qualidade do sono e níveis de stresse.
* **Análise Comportamental:** O sistema avalia os dados ao longo do tempo para detetar tendências negativas e sinais de exaustão.
* **Recomendações Personalizadas:** Oferece estratégias preventivas de autocuidado (como micro-meditações, pausas ativas e exercícios de respiração) ou incentiva a procura de apoio profissional quando necessário.

---

## Tecnologias Utilizadas

A arquitetura do projeto foi desenhada para garantir escalabilidade, performance e capacidade analítica:

* **Front-end Mobile:** React Native / Flutter (para aplicações multiplataforma fluidas).
* **Back-end:** Node.js com Express (para APIs REST robustas e eficientes).
* **Base de Dados:** 
  * *PostgreSQL:* Dados relacionais estruturados (utilizadores, perfis e históricos).
  * *MongoDB:* Dados não estruturados e logs dinâmicos.
* **Ciência de Dados & IA:** Python, Pandas e Scikit-learn (para modelagem preditiva e deteção de padrões de stresse).
